# Generative Agents：本项目核心笔记

来源：用户提供的 arXiv:2304.03442v2 英文论文，§4.1、§6–7；查阅日 2026-11-13。本文重新依据原论文和当前实现整理，不引用旧「记忆调研」目录的笔记或结果。

## 对课题的作用

提供一个已有记忆评分办法，用于对照：语义相关性 + 距上次访问的近因性 + 重要性。只复现这一检索模块，不复现小镇、地图和全部角色生活。

## 核心机制

每条记忆有内容、创建时间和最近访问时间。相关性是查询与记忆向量的余弦相似度；近因性是 `0.995 ** 距上次访问的游戏小时数`；重要性在创建记忆时由 LLM 按 1–10 分给出。三项分别 min-max 到 [0,1]，权重均为 1，再相加选高分记忆。论文没有给出权重学习或系统调参证据。

## 本项目已经做到哪一步

- `src/memory_rerank/scoring.py` 已独立实现论文式打分、时间可见性和离线状态隔离。
- 用固定合成分数测试公式方向；真实向量使用本地 multilingual-e5-small，并固定 revision。
- 原始论文的模型／重要性生成尚未复现。自建诊断题的 importance 是人工测试输入；公开 LongMemEval 没有该分数，暂用常数。因此**当前是评分机制的迁移与验证，不是原论文性能复现**。
- 零极差时置为 0.5、按 ID 处理并列，是明确的工程约定。

## 为什么值得改进

“刚被访问”不等于“当前有效”。旧地址即使刚被看过也可能已经失效。“对角色重要”也不等于“对当前任务有用”。这两个区别可以成为后续实验问题，但不能直接证明创新性或一定带来提升。

## 如何比较

在同一批记忆与查询上运行纯语义、语义+近因性和 GA 评分，再测正确证据排名。原文评估的是角色行为可信性，不可把其 TrueSkill 评分直接与本项目 Recall/NDCG 对比。

## 下一步

补充可缓存、可追溯的重要性评分；加入强语义重排器；把诊断题与独立评估数据分开。当前不能依据少量人工样例宣称 GA 较差或新方法较好。
