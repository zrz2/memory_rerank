# Generative Agents 核心阅读笔记

对应课题：**融合语义、时效与任务相关性的智能体记忆检索重排序方法研究**

## 1. 我的课题最终要做什么？

做一个**记忆排序程序**：智能体收到任务后，从历史记忆中选出最值得参考的几条，交给大语言模型。

例如，用户说：“帮我选一家酒店。”历史记忆中有：

- “去年住过某家酒店。”——提到了酒店，但不一定适合本次任务。
- “最近膝盖受伤，不能爬楼。”——没有提酒店，却会影响是否需要电梯。

课题要研究的是：**除了语义相似，怎样结合信息是否仍然有效、是否影响当前任务，把真正有用的记忆排到前面。**

最终成果：**一个排序方法及程序 + 一批测试题 + 与已有方法的比较结果。**

## 2. 这篇论文解决什么问题？

Generative Agents 想让虚拟角色在持续互动中记住经历、安排生活，并表现得连贯可信。它的完整系统包含记忆、检索、反思和规划。

**与我的课题最直接相关的是 §4.1 的记忆检索。** 小镇地图、角色走路、派对和完整日程系统，不是当前必须复现的部分。

## 3. 可以借用的核心方法是什么？

论文给每条记忆计算三项分数，调整到相同范围后相加，再优先选出高分记忆：

**总分 = 语义相关性 + 访问近因性 + 重要性。**

| 因素 | 通俗含义 | 论文做法 |
|---|---|---|
| 语义相关性 | 记忆与当前问题是否相关 | 比较文本向量的 cosine similarity |
| 访问近因性 | 最近是否访问过这条记忆 | 0.995 的“距上次访问小时数”次方 |
| 重要性 | 这段经历对角色是否重要 | LLM 在写入时打 1–10 分 |

三项分别做 min-max 归一化，权重都为 1。论文未报告系统调参过程，也没有证明这些权重最优。

**两个关键区别：**

- 最近访问过，不代表信息现在仍然有效。例如刚看过旧地址，旧地址也不会因此重新有效。
- 对角色重要，不代表对当前任务有用。例如失恋经历可能很重要，但通常不能帮助确认快递地址。

这两点是我的课题可以进一步研究的切入点，但是否有创新性，还需与其他相关工作比较。

## 4. 它提供了什么？我要复现什么？

它提供了一个明确、可实现的**已有记忆排序方法**，可以作为 baseline（基线，即比较对象）。

**当前只复现论文 §4.1 的排序机制：**计算三项分数 → 归一化 → 相加 → 排序 → 返回前几条记忆。

不需要先完整运行 25 个居民的小镇。公开代码与论文描述存在差异，起步时按论文定义实现，命名为 **GA-paper**，不要把它称为“完整复现整篇论文”。

## 5. 实验怎么比较？测试集是什么？

**测试集就是一套题目，以及判断对错的依据。** 对本课题，一道题需要有“历史记忆、当前任务、查询时间、正确记忆”。

例子：

| 内容 | 示例 |
|---|---|
| 历史记忆 M1 | 10 月：收货地址是 A |
| 历史记忆 M2 | 11 月：已经搬家，以后快递寄到 B |
| 当前问题 | 11 月 13 日，今天的快递寄到哪里？ |
| 正确记忆 | M2，应当排在前面 |

如果问题改成“10 月的地址是什么”，正确记忆就可能是 M1。因此，不能简单认为越新越好。

让下面的方法使用**同一批记忆、同一批问题、同一种评分标准**：

| 方法 | 用途 |
|---|---|
| 只看语义 | 最基本的参照 |
| GA-paper：语义 + 访问近因性 + 重要性 | 论文提供的基线 |
| 我的方法 | 检验对时效和任务相关性的处理是否有帮助 |

主要检查：

1. **找没找到正确记忆？** 看前 K 条是否包含正确证据，对应 Recall@K 等指标。
2. **正确记忆排得靠不靠前？** 对应 MRR、NDCG 等排名指标。
3. **有没有误选过时记忆？** 例如继续使用旧地址、旧日期。
4. **代价多大？** 记录耗时和模型调用成本。

再把自己增加的时间处理、任务相关性处理分别去掉，检查效果变化。这叫**消融实验**，用于判断每个新增部分是否真的有用。

## 6. 能直接使用原论文的实验成绩吗？

**不能直接比较，应该把它的方法放到我的测试题上重新运行。**

原论文主要评估虚拟角色的行为是否可信，以及消息传播、关系形成和活动协调。它没有直接报告我的课题需要的记忆排名指标。

它的实验支持“完整架构有助于可信行为”，不能直接证明“三项排序公式最优”。它也没有提供可以直接用于本课题的标准检索金标题库。

最值得借鉴的是：**保持记忆和其他条件相同，只改变要比较的方法。**

## 7. 我接下来做什么？

1. 读懂 §4.1，能解释三项分数的区别。
2. 手工做几个地址更新、计划改期、长期过敏信息和历史查询的例子，写清正确记忆。
3. 实现“只看语义”和“GA-paper”，观察真实排序和错误。
4. 根据错误设计自己的时效、任务相关性处理，再比较结果。

先用少量题目跑通流程，不能据此宣称方法普遍更好；后续再扩充测试集和更强的对照方法。

**一句话记住这篇论文的作用：它给了我一个现成的记忆排序基线；我要研究的是，在任务需要和信息有效性方面，能否做得更好，并通过相同题目的对比实验来验证。**
